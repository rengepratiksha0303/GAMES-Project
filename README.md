# Game Sales Prediction

This project predicts Global Game Sales using:

- KNN
- ANN
- CNN

## Installation

```bash
pip install -r requirements.txt
```

## Train Models

KNN

```bash
python train_knn.py
```

ANN

```bash
python train_ann.py
```

CNN

```bash
python train_cnn.py
```

## Run Streamlit App

```bash
streamlit run app.py
```

## Files Generated

- knn_model.pkl
- scaler.pkl
- ann_model.h5
- cnn_model.h5

## Dataset

Place:

```text
games.csv
```

inside project folder before training.
